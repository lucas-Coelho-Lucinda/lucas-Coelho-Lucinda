# 👋 Olá, eu sou o Lucas!

### Desenvolvedor de Software | Front-end • Back-end

Sou **Desenvolvedor de Software com mais de 3 anos de experiência** no desenvolvimento, manutenção e evolução de sistemas ERP corporativos em ambientes produtivos.

Atualmente, meu **foco principal está no desenvolvimento Front-end**, especialmente na construção de interfaces, componentes reutilizáveis e aplicações web utilizando **React, TypeScript e JavaScript**.

Também possuo **experiência prática com desenvolvimento Back-end**, principalmente utilizando **PHP**, além de experiência com **PostgreSQL e MySQL**. Ao longo da minha trajetória, já atuei na implementação de regras de negócio, integrações e manutenção de funcionalidades envolvendo diferentes camadas das aplicações.

Dessa forma, embora meu direcionamento atual seja mais forte para **Front-end**, também mantenho uma visão e experiência em **Back-end**, buscando ampliar continuamente meus conhecimentos para atuar de forma cada vez mais completa no desenvolvimento de software.

Atualmente, estou aprofundando meus conhecimentos em **arquitetura Front-end, componentes reutilizáveis, testes automatizados, qualidade de código e aplicações escaláveis**, enquanto também continuo estudando tecnologias e práticas de **desenvolvimento Back-end**.
